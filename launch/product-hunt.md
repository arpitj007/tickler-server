# Product Hunt

## Rules and norms (summary)

Sources: https://www.producthunt.com/launch/preparing-for-launch and https://www.producthunt.com/launch/launch-day-questions (checked 2026-11-06; the help center didn't load, so parts below are marked verify).

- Every upvote counts the same; spam and vote manipulation lower a launch's ranking. **Don't ask anyone to upvote.** Asking people to "check it out and share feedback" is fine.
- Post as a **maker** so you're shown as the developer. If someone else hunts it, make sure you're added as maker.
- A maker's **first comment** matters: most featured launches have one.
- Launch days start at **12:01 a.m. Pacific time** (verify in the scheduler).
- The product must be live and usable on launch day: both store listings approved, docs site up.

### Description (260 max)

```
Agents keep promising "later". Tickler gives them a calendar: any MCP client adds follow-ups, deadlines and runs to a server you host, and your phone shows them with a link back to the chat that decided it. Plus app sales and AI costs. Free, open source.
```

### Maker's first comment (draft; rewrite in your own words)

```
Hi Product Hunt, I'm [NAME], the developer of Tickler.

I use coding agents all day, and they constantly say things like "we should re-check this after the deploy" or "I'll set up a reminder for the cert renewal." Then the session ends and the promise is gone.

Tickler is my fix. It's a small open-source server you run yourself (one button on Cloudflare's free plan, or Docker), plus an iPhone and Android app. Any MCP client, Claude Code, Cursor, Codex, ChatGPT and others, can add entries. Each entry remembers where it came from, so on my phone I can tap back into the exact session, or copy the command that resumes it.

Things I cared about:
- Your data stays on your server. No account, no analytics, nothing comes to me.
- Setup in about 10 minutes, with guides in the app.
- A Money tab for indie developers: store sales, cloud and AI API costs, budgets and month-end forecasts, always with an "as of" time.

There's a demo mode if you want to look before setting anything up. I'd love to hear how you'd use it and what's missing. I'll be here all day.
```

## Launch day checklist

- [ ] Both apps live, docs up, demo server up.
- [ ] Schedule for 12:01 a.m. PT on a Tuesday to Thursday.
- [ ] First comment posted right away.
- [ ] Be around to answer comments for the whole day.
- [ ] Share the launch in your own channels with a plain "we launched" message, without "please upvote".
